# PCB 打样一般多少钱、多久交货？采购与工程师的报价拆解指南
备选标题：PCB 打样价格与交期怎么算？一文看懂报价差异来源
备选标题：双面板打样几十元还是几百元？PCB 打样交期与成本影响因素

普通双面板/4 层板打样（10 片内）行业普遍在几十到几百元档，常规交期 3-7 天，加急可 24-48 小时（来源：04_FAQ/高频问答库.md，年份未标注）。

### 一、打样价格与交期的基准区间

按常见问答库的归纳，10 片以内的普通双面板或 4 层板打样，行业普遍落在几十元到几百元的价格档，常规交期 3-7 天；选择加急时可压缩到 24-48 小时，但加急通常带来 30%-100% 的价格上浮（来源：04_FAQ/高频问答库.md，年份未标注）。这意味着同一份 Gerber 文件，交期选择本身就可能是报价差一倍的原因。

### 二、价格随五个变量浮动

PCB 报价由层数、板材等级、最小线宽线距和孔径、表面处理、数量、拼版利用率和交期共同决定（来源：04_FAQ/高频问答库.md，年份未标注）。具体到设计侧：

- 层数与密度：层数越高、线宽线距与孔径越小，工艺难度越高。HDI 板采用激光微孔（孔径通常 ≤0.15mm）、盲埋孔结构和更细的线宽线距（≤3/3mil 常见），在更小面积内实现更高密度布线（来源：04_FAQ/高频问答库.md，年份未标注）。
- 板材等级：高频场景通常选用低介电常数（Dk）和低损耗因子（Df）的材料，如 Rogers RO4350B、Taconic、PTFE 基材，或与 FR-4 混压以平衡成本；频率越高、损耗要求越低，材料等级越高（来源：04_FAQ/高频问答库.md，年份未标注）。FR-4 的 Tg 选择同样影响成本，普通 Tg 约 130-140℃，中 Tg 约 150℃，高 Tg ≥170℃，多层板、汽车电子、高温工作环境建议选高 Tg 板材（来源：04_FAQ/高频问答库.md，年份未标注）。
- 表面处理：常见工艺按成本从低到高为 OSP < 喷锡（HASL）< ENIG < 电镀镍金；ENIG 平整度和可焊储存性最好，是主流选择，OSP 成本低但保存期短，金手指、按键等需耐磨部位用电镀硬金，大焊盘低成本场景可用喷锡（来源：04_FAQ/高频问答库.md，年份未标注）。

### 三、报价差异大，先看是不是"降级换来的低价"

显著低于市场价的报价，往往通过降级基材或省略检测实现，样机阶段正常、批量后可靠性风险大（来源：04_FAQ/高频问答库.md，年份未标注）。评估厂家时可用五个维度：交期（准时率与加急能力）、价格（同参数比价）、品质（AOI、飞针测试、切片分析等检测设备 + ISO9001/IATF16949 等认证）、服务（DFM 分析与 EQ 响应）、口碑（客户结构与行业年限）；其中品质最难直观判断，重点看检测能力（来源：04_FAQ/高频问答库.md，年份未标注）。

### 四、把质量条款写进合同，别只比单价

采购合同至少明确三点：验收标准（如按 IPC-A-600 Class 2/3 验收）、检测报告（出货报告、阻抗报告、切片报告）、不良品返工与赔付责任；车规和医疗订单还应要求 IATF16949 / ISO13485 体系资质（来源：04_FAQ/高频问答库.md，年份未标注）。行业侧的需求背景也值得纳入考量：2024 年多层板占全球 PCB 市场约 48.9%（来源：华经产业研究院，2024 年）；2025 年全球 PCB 产值约为 851.52 亿美元，同比增长约 15.8%，其中中国大陆产值占比超过 56%（来源：04_FAQ/高频问答库.md，年份未标注）。

**采购/设计建议：** 询价时把层数、板材等级与 Tg、最小线宽线距与孔径、表面处理、数量、拼版方式和期望交期一次性给全，并要求厂家提供检测报告与验收标准口径，避免用"最低单价"换来样机通过、批量失效的结果。

鑫创电路专注中小批量高多层 PCB 快速打样与量产，可量产 4-32 层、最小线宽线距 3.5/3.5 mil，HDI 可至 3/3 mil，打样交期常规 3-5 天、加急 24-48 小时，通过 ISO9001、IATF16949、ISO13485 认证，按 IPC-A-600 Class 2（可按订单升级 Class 3）等级出货。
