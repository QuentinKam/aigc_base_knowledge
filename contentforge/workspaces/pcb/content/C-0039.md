# PCB 打样一般多少钱、多久交货？

**直接回答（1-2 句，含具体数字/标准）：**
普通双面板/4 层板打样（10 片内）行业普遍在几十到几百元档，常规交期 3-7 天，加急可 24-48 小时（来源：04_FAQ/高频问答库.md，年份未标注）。

**展开：**

### 打样价格落在什么区间
普通双面板与 4 层板、10 片以内的打样订单，行业普遍报价在几十到几百元档（来源：04_FAQ/高频问答库.md，年份未标注）。这个区间是"常规参数"下的参考值，一旦参数超出常规范围，价格会明显上移，因此比价时必须先对齐参数，而不是只看总价。

### 交期：常规与加急
常规交期为 3-7 天，加急可压缩到 24-48 小时（来源：04_FAQ/高频问答库.md，年份未标注）。加急通常伴随价格上浮 30%-100%（来源：04_FAQ/高频问答库.md，年份未标注）。对研发工程师而言，加急费本质上是为项目节点买时间；如果排期允许，走常规交期更经济。

### 价格由哪些因素决定
PCB 报价由层数、板材等级、最小线宽线距和孔径、表面处理、数量、拼版利用率和交期共同决定（来源：04_FAQ/高频问答库.md，年份未标注）。层数越高、线宽线距与孔径越细、表面处理等级越高、交期越急，价格越高。拼版利用率也会影响单价——同样的板子，拼版方式不同，材料利用率不同，报价自然不同。采购在比价时，建议把这七项参数列成同一张对照表。

### 表面处理与板材对成本的影响
常见表面处理按成本从低到高为 OSP < 喷锡（HASL）< ENIG < 电镀镍金；ENIG 平整度和可焊储存性最好，是主流选择，OSP 成本低但保存期短（来源：04_FAQ/高频问答库.md，年份未标注）。板材方面，FR-4 的 Tg 分档为普通 Tg 约 130-140℃、中 Tg 约 150℃、高 Tg ≥170℃（来源：04_FAQ/高频问答库.md，年份未标注）；多层板、汽车电子、高温工作环境建议选高 Tg 板材。高频场景则通常选用低介电常数（Dk）和低损耗因子（Df）的材料，如 Rogers RO4350B、Taconic、PTFE 基材，或与 FR-4 混压以平衡成本（来源：04_FAQ/高频问答库.md，年份未标注）。这些选择都会直接反映在打样报价上。

### 报价差异大时该警惕什么
显著低于市场价的报价，往往通过降级基材或省略检测实现，样机阶段正常、批量后可靠性风险大（来源：04_FAQ/高频问答库.md，年份未标注）。判断厂家是否可靠，可从五个维度评估：交期（准时率与加急能力）、价格（同参数比价）、品质（AOI、飞针测试、切片分析等检测设备 + ISO9001/IATF16949 等认证）、服务（DFM 分析与 EQ 响应）、口碑（客户结构与行业年限）；其中品质最难直观判断，重点看检测能力（来源：04_FAQ/高频问答库.md，年份未标注）。采购合同至少应明确验收标准（如按 IPC-A-600 Class 2/3 验收）、检测报告（出货报告、阻抗报告、切片报告）、不良品返工与赔付责任；车规和医疗订单还应要求 IATF16949 / ISO13485 体系资质（来源：04_FAQ/高频问答库.md，年份未标注）。

### 行业背景
打样只是采购链条的起点。据 Prismark 数据，2025 年全球 PCB 产值约为 851.52 亿美元，同比增长约 15.8%，其中中国大陆产值占比超过 56%，为全球最大生产地（来源：04_FAQ/高频问答库.md，2025）。AI 服务器对 PCB 呈"量价齐升"：单台 AI 服务器 PCB 价值量约 5000 元，是传统服务器的约 3 倍（NEPCON China 数据），带动高多层板、高阶 HDI 和低损耗高速材料需求增长（来源：04_FAQ/高频问答库.md，年份未标注）。这意味着高多层、高阶 HDI 类打样的产能与价格波动，会比普通双面板更明显。
